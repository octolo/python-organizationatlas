# organizationatlas

Python library for organization search and enrichment. One provider interface over several data sources (INSEE, data.gouv.fr, Huwise, INPI), via ProviderKit.

The PyPI name is `python-organizationatlas`; the directory holding it in this monorepo is `python-organizationatlas/`.

## Installation

```bash
pip install python-organizationatlas
```

## Requirements

Python 3.10+.
